# Project Overview
A platform where local communities can organize events, recruit volunteers, and track participation.
Key Features:

User registration with roles (Organizer, Volunteer, Admin)
Create, manage & RSVP to community events
Volunteer sign-up & hour tracking
Real-time notifications (SignalR)
Chat/discussion per event
Dashboard with analytics (attendance, volunteer stats)
Ratings & reviews for events
Map integration for event locations

# Tech Stack & Environment
- **Framework:** .Net Core 10
- **Language:** C#
- **Database/ORM:** Entity Framework Core with PostgreSQL
